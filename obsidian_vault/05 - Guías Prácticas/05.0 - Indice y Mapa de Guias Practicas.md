## Explicación Técnica

Este capítulo agrupa los procedimientos operativos estándar para la puesta en marcha, control de calidad, testing automatizado y despliegue en entornos de producción del ecosistema **QuestFest**.

### Contenidos del Capítulo

- [[05.1 - Manual de Encendido]] — Guía de arranque paso a paso del entorno de desarrollo local con Docker Compose, PostgreSQL, migraciones de Alembic y servidores de hot-reload para frontend y backend.
- [[05.2 - Suite de Pruebas Automatizadas y Garantia de Calidad]] — Protocolo de ejecución de pruebas unitarias y de integración con Pytest, pruebas asíncronas de base de datos, mocking de servicios externos y validación de tipos estáticos.
- [[05.3 - Despliegue en Produccion y Pipeline CI-CD]] — Procedimiento de puesta en producción con NGINX como proxy inverso TLS/SSL, imágenes optimizadas de Docker, gestión de variables secretas y automatización de entrega con GitHub Actions.

## Modelo Conceptual de Analogía: El Manual de Taller y Mantenimiento

Imagine la guía técnica que utilizan los ingenieros de vuelo o el equipo de mecánicos antes de autorizar el despegue de una aeronave.

No se trata de teorizar sobre la aerodinámica, sino de disponer de una lista de comprobaciones exacta: qué interruptores encender primero, cómo verificar que la presión hidráulica es la adecuada antes del vuelo y qué procedimiento de emergencia seguir si un componente no responde. Estas guías prácticas constituyen el manual de operaciones de QuestFest.
