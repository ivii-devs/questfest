## Procedimiento Técnico de Ejecución de Pruebas

Este manual detalla los procedimientos estandarizados para la ejecución de la suite de pruebas unitarias e integración en el entorno de desarrollo y la verificación de la calidad del software del proyecto **QuestFest**.

---

## 1. Configuración del Entorno de Pruebas en Backend (Pytest + SQLite Async)

Para evitar la contaminación de la base de datos de desarrollo y garantizar pruebas deterministas, la suite de backend utiliza una base de datos en memoria SQLite asíncrona (`sqlite+aiosqlite:///:memory:`).

### Instalación de Dependencias de Testing:
```bash
cd backend
pip install pytest pytest-asyncio httpx aiosqlite
```

### Ejecución de Pruebas Backend:
```bash
# Ejecutar todas las pruebas del directorio tests/
python -m pytest tests/

# Ejecutar con salida detallada y nivel de depuración
python -m pytest tests/ -v -s

# Ejecutar un módulo específico de pruebas
python -m pytest tests/test_ledger.py
```

---

## 2. Arquitectura de Fixtures de Testing (`conftest.py`)

El archivo de configuración de pruebas define los fixtures asíncronos para aislar la base de datos y simular el servidor API mediante el cliente HTTP de integración:

1. **Compilación de Dialectos (`compile_jsonb_sqlite`)**: Adapta los tipos de datos nativos de PostgreSQL como `JSONB` a columnas compatibles con SQLite (`JSON`).
2. **Fixture `db_session`**: Crea todas las tablas del esquema en memoria antes de cada función de prueba y las destruye al finalizar, garantizando un estado completamente limpio.
3. **Fixture `client`**: Sobrescribe la dependencia `get_db` de FastAPI mediante `dependency_overrides` y genera un cliente HTTP asíncrono (`httpx.AsyncClient`) con soporte para transportes ASGI (`ASGITransport`).

---

## 3. Verificación de Compilación y Calidad de Código Frontend

Para garantizar que los cambios en la interfaz no introduzcan errores de sintaxis o fallos de tipos en TypeScript, se ejecuta el proceso de build de producción:

```bash
cd frontend

# Verificación de sintaxis, tipos TypeScript y compilación Next.js Turbopack
npm run build
```
